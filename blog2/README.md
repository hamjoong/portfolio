# 프로젝트 : Developer Portfolio Blog

# 프로젝트 개요 :
개인 포트폴리오 블로그 프로젝트입니다. 개발자로서의 정체성, 보유 기술 스택, 그리고 그동안 진행해온 주요 프로젝트들을 한눈에 확인할 수 있도록 인터랙티브하게 설계되었습니다. 방문자에게 전문적인 인상을 주기 위해 모던한 UI 디자인을 채택했으며, 다양한 디바이스에 대응하는 반응형 웹 기술을 적용했습니다.

# 스킬 스택 :
- **Markup**: Pug (HTML Preprocessor)
- **Styling**: CSS (Bootstrap 5)
- **Script**: JavaScript (ES6+), jQuery
- **Icons**: Font Awesome, XEIcon
- **Fonts**: Google Fonts (Montserrat, Lato)

# 스킬 선택 이유 :
- **Pug**: HTML의 반복적인 마크업 작업을 믹스인(Mixins)을 통해 모듈화하여 가독성을 높이고 유지보수 효율을 극대화했습니다.
- **Bootstrap 5**: 검증된 레이아웃 시스템과 모달(Modal), 내비게이션 바 등 고품질 컴포넌트를 활용하여 일관된 디자인과 빠른 개발 속도를 확보했습니다.
- **jQuery**: 복잡한 DOM 조작과 스크롤 애니메이션 등 인터랙티브한 요소들을 간결하고 직관적인 코드로 구현했습니다.
- **Google Fonts & Icons**: 시각적으로 완성도 높은 디자인을 위해 전문적인 웹 폰트와 아이콘 라이브러리를 활용했습니다.

# 아키텍처 :
- **Static Site Architecture**: 별도의 서버 없이 클라이언트 사이드 기술만으로 구성된 고성능 정적 웹사이트입니다.
- **Source (src/)**: Pug 템플릿과 스타일/스크립트 원본 소스가 위치합니다.
- **Build (build/)**: 배포를 위해 컴파일된 HTML 및 리소스가 저장됩니다.
- **Public (public/)**: 이미지, 파비콘 등 정적인 자산을 관리합니다.

# 프로젝트 구조 :
- `src/pug`: 화면 구조를 정의하는 Pug 템플릿 파일
- `src/css`: 프로젝트의 핵심 스타일 시트 (blog.css)
- `src/script`: 동적 기능을 담당하는 JavaScript 파일 (blog.js)
- `build/html`: Pug에서 컴파일된 최종 HTML 파일
- `public/favicon`: 파비콘 아이콘 리소스
- `public/img`: 포트폴리오 및 프로필 이미지 리소스

# 핵심 트러블 슈팅 :
- **문제**: 포트폴리오 항목 증가에 따른 HTML 코드 비대화 및 가독성 저하.
- **원인**: 반복되는 이미지 경로, 제목, 설명 등이 포함된 모달 구조가 전체 마크업의 상당 부분을 차지함.
- **해결**: Pug의 `mixin` 기능을 도입하여 `portfolio-item`과 `portfolio-modal` 템플릿 함수를 정의하고 데이터만 파라미터로 전달하도록 구조화하여 마크업 코드를 80% 이상 경량화함.
- **배운 점**: 전처리기를 활용한 컴포넌트 기반 설계가 대규모 마크업 작업에서 얼마나 높은 생산성과 유지보수성을 제공하는지 체감할 수 있었습니다.

# 기술적 개선 및 보안 :
- **SEO 및 메타 정보**: `description` 및 `author` 메타 태그를 보강하여 검색 엔진 최적화와 작성자 정보를 명확히 했습니다.
- **웹 표준 준수**: 파비콘 로드 시 잘못된 MIME Type을 수정하고 유효한 형식을 지정했습니다.
- **성능 최적화**: 모든 이미지에 `loading='lazy'` 속성을 적용하여 초기 로딩 속도를 개선하고 네트워크 자원을 효율적으로 관리합니다.
