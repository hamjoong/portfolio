# 🎬 Movie Box

> 최신 영화 차트 및 상영 예정작 정보를 직관적으로 제공하고 YouTube 예고편을 연동한 반응형 영화 정보 웹 플랫폼

---

## 📌 프로젝트 개요
- **서비스명**: Movie Box
- **설명**: 최신 박스오피스 순위와 개봉 예정작 정보를 한눈에 탐색하고, 각 영화의 공식 예고편을 즉시 감상할 수 있는 웹 서비스입니다.
- **반응형 웹 지원**:
  - **PC 환경**: 시각적 몰입감을 극대화한 대화면 레이아웃과 YouTube Iframe 트레일러 연동 플레이어를 제공합니다.
  - **모바일 환경 (768px 이하)**: 미디어 쿼리를 통해 모바일 전용 뷰(`mini_box`)로 전환되어 개봉일 및 순위 정보를 효율적인 카드 그리드 리스트로 제공합니다.

---

## 🛠 기술 스택

| 분류 | 기술 |
| :--- | :--- |
| **Markup / Template** | `Pug` (HTML Template Engine) |
| **Styling** | `SCSS (Sass)`, `Google Fonts (Gowun Dodum)`, `Xeicon` |
| **Script / Library** | `JavaScript (ES6+)`, `jQuery 3.6.0` |

---

## 💡 기술 선택 이유

- **Pug**: 중첩된 HTML 구조를 들여쓰기 기반의 간결한 코드로 작성하여 유지보수성과 마크업 구조 파악 속도를 향상시켰습니다.
- **SCSS**: `@mixin`을 통한 레이아웃(메인 박스, 헤더 등) 모듈화 및 재사용, 그리고 `@for` 반복문을 활용해 12개 이상의 영화 포스터 배경 이미지 경로를 선언적으로 자동화 처리했습니다.
- **jQuery**: 탭 전환('무비차트' vs '상영예정작'), 계층형 드롭다운 메뉴, 선택한 영화 포스터에 대응하는 YouTube 트레일러 전환 인터랙션을 빠르고 안정적으로 구현하기 위해 선택했습니다.

## ✨ 핵심 기능

1. **GNB & 드롭다운 네비게이션**: 상단 메뉴에 마우스 호버 시 부드러운 슬라이드 인터랙션으로 하위 메뉴 노출
2. **영화 카테고리 탭 스위칭**: '무비차트'와 '상영예정작' 탭 선택에 따라 각 섹션 포스터 목록을 즉각적으로 전환
3. **YouTube 트레일러 연동 플레이어**: 포스터 클릭 시 해당 영화에 매핑된 공식 예고편(1~12번)으로 동적 전환
4. **디바이스별 반응형 레이아웃 스위칭 (Media Query)**:
   - 768px 초과: 대화면 포스터 그리드와 트레일러 플레이어가 결합된 PC 뷰
   - 768px 이하: 터치 디바이스에 최적화된 모바일 전용 순위 리스트 뷰(`mini_box`)

## 🔍 핵심 트러블 슈팅 & 개선 사항

### 1. 탭 전환 시 상호 배타적 컨테이너 제어
- **문제**: '무비차트'와 '상영예정작' 탭 전환 시 두 리스트가 겹치거나 이전 탭의 잔여 요소가 시각적으로 충돌하는 현상 발생.
- **원인**: 탭 전환 로직에서 활성 컨테이너와 비활성 컨테이너의 표시/숨김 처리가 명확히 분리되지 않음.
- **해결**: jQuery 이벤트 핸들러에서 탭 상태값(`isChart2`)을 기반으로 각 컨테이너(`.movie_img_box` / `.movie_img_box2`)를 상호 배타적으로 `.toggle()` 처리하고 활성화된 탭의 버튼 스타일을 동적으로 갱신하여 해결했습니다.

### 2. 예고편 전환 시 백그라운드 영상 중복 재생(오디오 잔류) 방지
- **문제**: 포스터를 클릭하여 새 예고편으로 전환하거나 탭을 바꿨을 때, 기존에 재생 중이던 YouTube `<iframe>`의 오디오가 백그라운드에서 계속 재생되는 현상.
- **원인**: 단순히 DOM 요소를 `hide()`하더라도 `<iframe>`의 스트리밍 상태는 정지되지 않음.
- **해결**: 트레일러 전환 및 탭 전환 시점에 모든 트레일러 iframe의 `src` 속성을 재할당(`stopAllTrailers`)하여 기존 영상 재생을 확실하게 정지 및 초기화하도록 로직을 개선했습니다.

### 3. SCSS 반복문(`@for`)을 활용한 대량 에셋 관리 자동화
- **문제**: 24개 이상의 영화 포스터 이미지 클래스를 개별적으로 선언할 경우 코드 중복과 유지보수 부담 발생.
- **해결**: SCSS의 `@for $i from 1 through 12` 및 삼항 연산 조건문을 활용하여 이미지 파일 번호와 클래스 선택자를 단 몇 줄의 제어문으로 동적 생성했습니다.
