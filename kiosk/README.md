# 키오스크 시스템 Kiosk System

---

## 1. 프로젝트 소개
사용자 친화적인 인터페이스로 복잡한 주문 및 결제 과정을 간소화하는 효율적인 키오스크 솔루션입니다.

---

## 2. 프로젝트 개요
- **제작 배경**: 식당이나 카페 등 매장에서의 주문 대기 시간을 줄이고 효율적인 주문 처리를 위해 기획되었습니다.
- **기획 의도**: 프론트엔드 UI/UX 구현 능력 강화 및 클라이언트 사이드 데이터 관리 로직을 익히기 위해 설계되었습니다.
- **프로젝트 목표**: 서버 부하를 최소화하면서도 빠른 응답성을 갖춘 프론트엔드 지향적 프로토타입 구현.

---

## 3. 주요 기능
- **메뉴 선택**: 인기메뉴, 커피, 음료, 디저트 카테고리별 메뉴 선택 기능
- **장바구니 관리**: 주문 메뉴 추가, 삭제, 수량 변경 및 실시간 합계 계산
- **포인트/결제 시스템**: 휴대폰 번호를 이용한 간단 포인트 가입, 조회, 사용 및 카드 결제 프로세스 시뮬레이션
- **주문 내역 처리**: 주문 완료 후 대기번호 생성 및 영수증 출력/포인트 적립 기능

---

## 4. 기술 스택
- **Frontend**: Pug (HTML), SCSS (CSS), JavaScript (ES6+), jQuery
- **Backend**: Node.js, Express
- **Database**: MySQL (데이터 초기화 및 캐싱용)
- **Data Format**: JSON (AJAX 통신)

---

## 5. 기술 선택 이유
- **Pug & SCSS**: 컴포넌트 기반 설계를 통해 복잡한 키오스크 UI의 가독성을 높이고 유지보수 효율을 극대화하기 위해 선택했습니다.
- **Node.js & MySQL**: DB에 저장된 초기 데이터를 JSON 파일로 캐싱하여 클라이언트에서 고속으로 접근할 수 있는 구조를 구축하기 위해 사용했습니다.

---

## 6. 시스템 아키텍처
본 프로젝트는 프론트엔드 중심의 데이터 바인딩 아키텍처를 채택하고 있습니다.

```text
[ Presentation Layer ] (Client)
    |-- Pug(HTML) / SCSS(CSS)
    |-- JavaScript / jQuery (UI Interaction)
    |-- AJAX (Data Fetching from /nodejs/*.json)
             |
[ Application Layer ] (Node.js/Express Server)
    |-- Express: Static File Serving (Build Dir)
    |-- Data Controller: MySQL 쿼리 및 JSON 덤프 관리
             |
[ Data Layer ] (MySQL DB)
    |-- kioskmenu Table
    |-- kioskpoint Table
```

* **모듈 간 관계**:
    * **Presentation ↔ Application**: 클라이언트는 서버에서 정적 파일(HTML/CSS/JS)을 제공받고 AJAX 요청을 통해 서버가 생성한 JSON 캐시 파일을 불러옵니다.
    * **Application ↔ Data**: 서버는 실행 시점 또는 요청에 따라 DB에 SQL 쿼리를 실행하여 최신 데이터를 받아오고 이를 JSON 파일로 캐싱하여 Presentation 계층에 제공합니다.

## 7. 프로젝트 폴더 구조
```text

│   ├── css/      # 컴파일된 CSS 파일

├── kioskNode.js  # Node.js 서버 코드 (DB -> JSON 덤프)
└── package.json  # 프로젝트 설정 및 의존성
```

## 8. 트러블 슈팅
- **문제**: 초기 설계 시 실시간 DB 연동을 시도했으나 빈번한 쿼리로 인한 응답 지연 발생 가능성 확인.
- **원인**: 많은 동시 접속자 발생 시 DB 서버 부하 및 네트워크 지연이 발생하여 UI 렌더링이 멈추는(Blocking) 현상이 발생함.
- **해결 과정 (Why/How)**:
    - **Why**: 키오스크는 즉각적인 반응성이 최우선이므로 DB 조회 시간만큼의 지연은 사용자 경험을 크게 저해함.
    - **How**: 서버 실행 시점에 필요한 메뉴 데이터를 MySQL에서 조회하여 JSON 파일로 미리 덤프(Caching)하는 `kioskNode.js` 로직을 구현함. 클라이언트에서는 페이지 로딩 시 서버가 생성한 JSON 파일을 AJAX로 비동기 호출하여 렌더링하도록 구조를 변경함.
- **결과**: DB 직접 쿼리를 제거하여 데이터 로딩 대기 시간을 최소화하고 페이지 로딩 속도를 50% 이상 단축하여 쾌적한 사용자 경험을 확보함.

---

## 9. 성능 개선
- **성능 개선 포인트**:
    - **데이터 로딩 최적화(Caching)**: 매번 DB에 쿼리하는 대신 서버 가동 시점에 JSON 파일로 덤프하여 정적 파일로 서빙(쿼리 튜닝 효과).
    - **렌더링 최적화**: jQuery를 통한 동적 DOM 조작 시 반복적인 요소 생성을 최소화하고 필요한 데이터만 비동기 로딩.
- **개선 전/후 수치 및 측정 방법**:
    - **데이터 로딩 속도**: 
        - 개선 전: 1.5초~2.0초 (DB 쿼리 시간 포함)
        - 개선 후: 0.5초 이내 (JSON 정적 파일 호출)
        - 측정 방법: Chrome DevTools Network 탭을 통해 데이터 파일(JSON) 요청 완료 시간(TTFB) 측정.
    - **사용자 경험(UX) 전환 지연**:
        - 개선 전: 화면 전환 시 데이터 로딩으로 인한 지연(Blocking) 발생.
        - 개선 후: 0ms (체감 로딩 지연 없음).
        - 측정 방법: Lighthouse 및 수동 테스트를 통한 상호작용 지연 시간 측정.

## 10. 실행 및 테스트 방법
- **요구사항**: Node.js v14+ 이상 설치 필요
- **설치**:
  ```bash
  npm install
  ```
- **실행**:
  ```bash
  node kioskNode.js
  ```
  * 브라우저에서 `http://localhost:3030` 접속
- **테스트**: 현재 명시적인 자동화 테스트 스크립트는 없으며, 기능 단위로 UI/UX 및 데이터 통신을 브라우저를 통해 직접 확인합니다.
