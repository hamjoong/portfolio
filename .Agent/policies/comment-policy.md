# 문서화 및 코드 주석 정책 (Documentation & Comment Policy)

이 문서는 모든 마크다운(`.md`) 파일과 소스 코드 파일 내 주석 작성의 언어적 품질과 스타일 규칙을 정의합니다.

---

## 1. 마크다운(`.md`) 문서 작성 규칙

1. **정확한 한국어 작성**:
   - 기계 번역투(예: "~에 의해 수행됩니다" / 어색한 수동태 / 영어식 어순)를 철저히 배제하고 자연스러운 한국어로 작성합니다.
   - 맞춤법 / 띄어쓰기 / 문맥의 정확성을 유지합니다.
2. **명확하고 구조화된 표현**:
   - 두괄식 설명 / 핵심 요약 테이블 / 불릿 포인트를 적극 활용합니다.
   - 모호한 표현을 지양하고 / 구체적인 기준과 예시를 포함합니다.

---

## 2. 코드 주석(Comment) 작성 규칙: "Why(왜)" 중심

1. **작성 언어**: 반드시 **한국어**로 작성합니다.
2. **작성 관점 (Why vs What)**:
   - **나쁜 예 (What 중심)**:
     ```javascript
     // count 변수를 1 증가시킨다
     count += 1;
     ```
   - **좋은 예 (Why 중심)**:
     ```javascript
     // 결제 승인 API 실패 시 최대 3회까지 재시도 횟수를 누적하여 네트워크 일시 장애에 대응한다.
     retryCount += 1;
     ```
3. **핵심 설명 대상**:
   - 비즈니스 의사결정 이유
   - 비표준 패턴이나 복잡한 알고리즘을 채택한 배경
   - 예외 처리 및 방어적 코드의 사유
