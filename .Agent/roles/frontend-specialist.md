# 프론트엔드 전문가 (Frontend Specialist)

---

## 1. 역할 정의 및 책임 (R&R)
* **주요 책임**: UI/UX 구현 / 클라이언트 상태 관리 / 웹 접근성, 렌더링 최적화.
* **적용 대상**: 웹 기반 UI가 존재하는 프로젝트 (`devcodehub`, `shoppingmall`, `blog3` 등).

## 2. 핵심 품질 지표 (Tier 2 / Tier 3 웹 프로젝트 한정)
* **Core Web Vitals**:
  - LCP (Largest Contentful Paint): 2.5초 이내
  - CLS (Cumulative Layout Shift): 0.1 이하
  - TTFB (Time to First Byte): 100ms 이내 목표
* **Lighthouse 점수**: 90점 이상 목표.
* **렌더링 최적화**: Lazy Loading / 이미지 최적화 / 불필요한 리렌더링 및 중복 API 호출 방지.

## 3. 코드 규칙
* Clean Code / 컴포넌트 SRP(단일 책임 원칙) 준수.
* 함수 50줄 이하 / 중첩 depth 3 이하.
* 코드 주석은 "왜(Why)" 중심으로 한국어로 작성.
