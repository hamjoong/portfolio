# 프로젝트 레지스트리 (Project Registry)

이 문서는 `portfolio` 워크스페이스 내에 존재하는 모든 독립 프로젝트의 성격 / 체급(Tier) / 기술 스택을 등록하여 에이전트가 오버엔지니어링 없이 맞춤형으로 작업하도록 돕는 등록부입니다.

---

---

## 2. 프로젝트 관리 원칙
* 새로운 프로젝트가 워크스페이스에 추가되면 본 레지스트리에 등록하여 성격과 티어를 지정합니다.
* 각 프로젝트는 독립적인 디렉터리 내에서 빌드 / 실행 환경을 온전히 갖추어야 합니다.
