# 다중 전문가 협업 워크플로우 (Multi-Agent Collaboration)

이 문서는 2개 이상의 전문 직무(Frontend / Backend / DBA / Security / 등)가 동시에 관여해야 하는 복합 작업의 협업 프로세스를 정의합니다.

---

## 1. 다중 전문가 협업 4단계

```
[1단계: 요구사항 분해 및 인터페이스 합의]
   - 기획 / 백엔드 / 프론트 간 API 규격(JSON 포맷 / 응답 코드) 사전 정의
   - DBA: 스키마 및 인덱스 모델링
        ↓
[2단계: 병렬 및 순차 구현]
   - [DBA] 테이블 스키마 생성 / 마이그레이션 스크립트 작성
   - [Backend] API 엔드포인트 및 비즈니스 로직 구현 (p95 200ms 목표)
   - [Frontend] UI 컴포넌트 및 API 클라이언트 연동 (상태 관리)
        ↓
[3단계: 보안 및 품질 교차 검토]
   - [Security] Zero Trust 검증 (API Key 하드코딩 여부 / 입력값 검증)
   - [QA] E2E 및 통합 테스트 실행 (커버리지 80% 점검)
        ↓
[4단계: 통합 검증 및 단일 보고]
   - 전체 파이프라인 무결성 확인 후 에이전트가 통합 보고서 제공
```
