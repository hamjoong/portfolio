# Level 1 무변경 심층 분석 워크플로우 (Analysis Workflow)

이 문서는 시스템 / 코드 / 의존성 / 아키텍처 / Git 상태를 분석할 때 **단 1바이트의 파일 변경도 없이(Zero-Mutation)** 안전하게 정보를 도출하는 절차를 정의합니다.

---

## 1. 분석 6대 영역

1. **소스 코드 흐름 분석**: 파일 간 호출 관계 / 제어 흐름 / 데이터 흐름 파악.
2. **프로젝트 구조 및 경계 분석**: 디렉터리 구성 / 모듈 분리도 / 상대 경로 침범 여부 점검.
3. **의존성 분석**: `package.json`, `requirements.txt` 내 라이브러리 버전 및 취약점 / 레거시 상태 점검.
4. **테스트 및 빌드 환경 분석**: 기존 단위 테스트 파일 유무 / 빌드 스크립트 정상 동작 여부(Dry-run).
5. **문서 및 주석 분석**: 기존 README 완성도 / Why 주석 적용 상태 확인.
6. **Git 상태 분석**: `git status` / `git diff` / `git log -n <N>` / `git branch` 조회.

---

## 2. 분석 실행 원칙

* **수정 금지 (No-Write)**: 임시 파일이나 분석용 로그를 워크스페이스에 남기지 않습니다.
* **사실 기반 보고**: 추측성 분석을 배제하고 / 실제 코드의 줄 번호와 구체적인 파일 경로를 근거로 제시합니다.
* **보고서 포맷**:
  - 프로젝트 개요 및 현재 스택
  - 강점 및 준수 현황
  - 잠재적 리스크 및 개선 권장사항 (우선순위 순)
