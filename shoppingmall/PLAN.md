# 쇼핑몰 프로젝트 기능 개선 로드맵

## 1. 개요
본 프로젝트의 안정성, 보안성, 유지보수성 향상을 목적으로 하며, 시니어 전문가 협업 기준(QA, 보안, 백엔드/프론트엔드 등)을 준수합니다.

## 2. Phase 1: 결제 기반 마련 및 Validation 적용
- **목표**: 서버 기반 결제 검증 프로세스 구축 및 입력 데이터 유효성 강화.
- **주요 작업**:
    - `MockPaymentService` 인터페이스 정의 및 구현.
    - `OrderController` 내 결제 검증 엔드포인트(`verify`) 추가.
    - 입력 DTO(예: `PaymentRequest`)에 Bean Validation 적용.
    - `GlobalExceptionHandler` 에러 응답 포맷 표준화.

## 3. Phase 2: 비즈니스 로직 고도화
- **목표**: 취소/환불 시 정합성 보장 및 성능 최적화.
- **주요 작업**:
    - `OrderService.cancelOrder` 내 재고 원복 로직 원자적 구현.
    - `ProductSearchService` QueryDSL 최적화 및 DB 인덱스 검토.

## 4. Phase 3: 회원관리
- **목표**: 회원관리 기능 구현 및 운영 환경 오류 수정
- **주요 작업**:
    - 아이디 찾기 기능 구현 및 운영 환경 버그 수정 (정보 불일치 오류 해결)
    - 비밀번호 찾기 기능 구현 및 운영 환경 버그 수정 (정보 불일치 오류 해결)
    - 소셜로그인 (UI/UX 모사 및 동작 흐름 구현)
    - 마이페이지 회원탈퇴 기능 구현 및 운영 환경 버그 수정 (처리 실패 오류 해결)

## 5. Phase 4: 상품 관리 탐색
- **목표**: 상품 관리 탐색 관련된 기능
- **주요 작업**:
    - 상품 상세페이지 기능에서 구매하는 과정에서 상품별 옵션 선택 기능 구현 (옷상품의 경우:사이즈/색상 , 전자기기의 경우:사양)

## 6. Phase 5: 주문 프로세스
- **목표**: 사용자의 상품 선택 후 주문 관련된 기능
- **주요 작업**:
    - 장바구니 기능 중 장바구니의 모든 상품을 일괄구매도 가능하지만 그 상품중 선택하여 구매 가능한 기능

## 7. Phase 6: 관리자 페이지 프로세스
- **목표**: 쇼핑몰 사용자의 회원/주문상품/주문수량 등 전반적인 관리자 기능
- **주요 작업**:
    - 상품 등록, 수정, 삭제
    - 전체 주문 관리 (주문 상태 변경: 결제완료 -> 상품준비중 -> 배송중 -> 배송완료)
    - 회원 관리 및 통계 (간단한 매출 그래프나 회원 수 조회 등)

## 8. Phase 7: 코드 정비 및 운영 환경 최적화
- **목표**: 운영 유지보수성 향상 및 리소스 경량화.
- **주요 작업**:
    - `MockConfig` Phase 1,2 번과 관련된 기능은 제외 테스트용 설정 제거.
    - 하드코딩된 설정값 환경변수화.
    - SLF4J 로깅 전환 및 불필요 로그 제거.

## 9. 실행 원칙
- 모든 변경사항은 단위 테스트 및 통합 테스트 검증 후 병합.
- 보안 승인 필수 항목(환경변수 전환 등)은 철저히 준수.
- 성능 최적화(Phase 2) 이후에는 기능 변경 금지(Regression Test 수행).
