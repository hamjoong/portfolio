# [PRD] DevCodeHub - 취준생 & 주니어 개발자를 위한 실전 코드 피드백 + 커뮤니티 플랫폼

## 1. 프로젝트 개요 (Project Overview)
- **서비스명**: DevCodeHub
- **목표**: AI 분석과 시니어 리뷰를 통해 개발자의 실질적인 성장을 돕는 코드 리뷰 플랫폼

## 2. 제품 비전 & 목표 (Vision & Goals)
- **비전**: 코드 리뷰 기반의 개발자 성장 생태계
- **핵심 목표**:
  - AI를 활용한 빠른 코드 피드백
  - 시니어와 주니어 개발자 간의 기술 지식 교류
  - 성능과 보안을 고려한 안정적인 시스템 구축

## 3. 핵심 기능 명세 (Core Features)
- **인증**: OAuth 2.0(Google, GitHub, Kakao, Naver) 및 JWT 기반 자체 인증
- **게시판**: SKILL/AI 분류, 태그 검색, 좋아요/북마크, 댓글
- **코드 리뷰**: AI 병렬 분석(Gemini/Claude/OpenAI, 키가 등록된 모델만 사용 가능), 시니어 하이브리드 매칭
- **채팅·알림**: WebSocket(STOMP) 실시간 1:1/그룹 채팅, 안 읽은 메시지 수, 실시간 알림, (선택) Redis 기반 다중 서버 전파
- **게이미피케이션**: 경험치·레벨, 활동 기반 뱃지, 랭킹, **활동 잔디**(최근 1년 활동량)
- **수익화(모의)**: 크레딧, 시니어 리뷰 중개 수수료(10%), 구독 모델. PortOne **테스트 결제**로 서버 검증까지 수행
- **사용자 편의**: 비회원(Guest) 모드(AI 리뷰 누적 3회·100줄 이하)

## 4. 사용자 유형
- **End User (Junior)**: 주니어·취준생 (AI/시니어 리뷰 이용)
- **Senior**: 코드 리뷰 제공 및 크레딧 보상 (인증 절차 필요)
- **Admin**: 통계 대시보드, 불량 콘텐츠 제재, 시니어 인증 심사, 감사 로그 확인

## 5. 성공 기준
- 결제·정산 흐름에서 중복 지급, 금액 위변조, 타인 결제 도용이 발생하지 않을 것
- 공개되지 않아야 할 정보(관리자 API, 타인의 채팅·유료 리뷰)가 인증 없이 조회되지 않을 것
- 375px 폭의 모바일 화면에서 가로 스크롤이 생기지 않을 것
- 로그에 개인정보가 평문으로 남지 않을 것
